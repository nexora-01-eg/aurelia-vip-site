# AURELIA / 03 — VIP Cinematic Website

A complete image-forward cinematic web experience.

Highlights:
- Real photography integrated into the narrative
- Pinned horizontal cinematic gallery
- Three.js/WebGL atmospheric object
- Bloom post-processing
- GSAP + ScrollTrigger transitions
- Lenis smooth scrolling
- Cursor interaction
- Scroll progress
- Editorial oversized typography
- Image reveal and hover choreography
- Responsive mobile layout
- No build step required

The demo uses remote Unsplash images so the ZIP stays lightweight. For production, download/replace those image URLs with licensed local assets and add optimized WebP/AVIF + poster images.
